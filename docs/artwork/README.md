# Phase Tuner artwork

`phase-tuner-source.png` is the original AI-generated artwork made for this mod
with the imagegen tool. The design is an obsidian-handled tuning tool with a
copper fork, violet crystal and redstone inset, isolated on transparent alpha.

The game asset is `src/main/resources/assets/pointportals/textures/item/tuner.png`:
a 32×32 RGBA reduction using nearest-neighbor sampling, with transparency kept.
The full-resolution source is documentation only and is not packaged in the mod.
The generated item model refers to `pointportals:item/tuner`.
